# 🐾 Dog Life Dashboard

## Overview
A fun data analytics project tracking park time, food intake, and expenses for my two dogs (Ody & Pluto).

## Why I Built This
As someone interested in data analytics, I wanted to apply data tracking to everyday life. This project demonstrates how simple datasets can generate meaningful insights.

## Tools Used
- Python
- pandas
- matplotlib

## Skills Demonstrated
- Data grouping and aggregation
- Data visualization
- Real-world application of analytics
